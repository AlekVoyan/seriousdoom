# ФАЄРВОЛ

Воксельный ретро-шутер: ты последний фаервол, который держит порт под DDoS.
Волна за волной, одна просторная арена, гонорар за каждую отбитую волну.

Меню и подача — поклон Doom 1993. Устройство волн, типы тварей и режим
выживания — от Serious Sam. Всё нарисовано кубами и собрано кодом: ни одного
импортированного меша.

Отделено от [VoxEvasion](https://github.com/AlekVoyan) — сатирической игры про
уклонение от ТЦК, где это одна из мини-игр («Фриланс — отбить DDoS»).

## Запуск

```bash
npm install
npm run dev
```

Игра на `http://localhost:5180/`, витрина ассетов — на `/assets.html`.

## Управление

| | |
|---|---|
| мышь | обзор (клик — захват курсора) |
| W A S D | ход и стрейф |
| ЛКМ / Space / Ctrl | огонь |
| 1 2 3 4 | пистолет, дробовик, пулемёт, ракетница (с 16-й волны) |
| Esc | выход |
| F3 | счётчик производительности |

## Читы и отладка

Как в думе: на титуле набери **IDCLEV** и две цифры волны — прыжок сразу
туда (IDCLEV16 → шестнадцатая). Раскладка не важна, набор по кодам клавиш.

То же через адрес: `?wave=16` — старт с волны, `?perf=1` — счётчик сразу,
`?edit=1` — сразу в редактор.

## Редактор арены

Пункт «РЕДАКТОР АРЕНИ» в титуле. Управление как в креативе майнкрафта:
летаешь от первого лица, прицел подсвечивает клетку, хотбар снизу.

| | |
|---|---|
| WASD + Space / Shift | полёт (зажать R — быстрее) |
| мышь / стрелки | обзор |
| ЛКМ | поставить выбранное |
| ПКМ / X | убрать то, что под прицелом |
| 0-9 / колесо | слот хотбара |
| G | сыграть на этой арене |
| Q | назад в титул |
| − / + | размер арены (32×32 … 80×80) |
| B | небо: пекло → закат → день |
| K | сохранить арену под именем |
| L | загрузить (или «-имя» — удалить) |
| N | загрузить базовую арену |
| E / I | экспорт в буфер / импорт из JSON |

Редактируется всё: размер арены, небо, пилоны двух размеров, факелы,
печати спавна (минимум две), пикапы и точка старта. Правки автосохраняются
в черновик; K раскладывает по именам. В титуле переключатель «АРЕНА: …»
листает базовую, встроенные, черновик и свои. JSON можно слать друг другу.

Встроенные арены: «ПІРАМІДА» — двор под открытым дневным небом с обелиском
и колоннадами, оммаж Serious Sam TFE; «КЕМПГРАУНД» — тесные сумеречные
дворики с мегааптечкой в центре, оммаж Q3DM6 из Quake 3.

Потолки: 14 пилонов, 12 факелов, 10 печатей, 24 предмета — у света на
арене есть цена, см. раздел «Как устроено».

Есть тач-раскладка: два стика и кнопка огня, появляются сами на сенсорном экране.

## Твари

| | роль |
|---|---|
| **Гнар** | филлер, прёт напролом |
| **Бомбист** | камикадзе, воет всю дорогу и взрывается вплотную |
| **Скакун** | приседает, прыгает по прямой и пролетает насквозь — есть окно уклониться |
| **Рогач** | разгоняется и таранит, промахнувшись — уносится дальше |
| **Гарпия** | летит синусоидой, пикирует вблизи |
| **Механоид** | стрелок, держит дистанцию, не бьёт сквозь укрытия |

С четвёртой волны появляются ветераны: краснее, живучее и с дополнительными
деталями на модели. Каждая пятая волна — наплыв камикадзе.

## Как устроено

Три.js на перспективной камере, поверх — 2D-канвас для HUD в духе статус-бара
1993 года. Монстры появляются не мгновенно: за две секунды до выхода рунная
печать разгорается, поднимает вращающуюся голограмму и столб искр — есть время
развернуться.

Звук позиционный: громкость, панорама и глухота считаются от расстояния до
источника, у камикадзе непрерывный вой, который едет вместе с ним. Музыка
меняется по ситуации с равномощными кроссфейдами — бой, передышка, смерть.

Отрисовка собрана вокруг двух правил, добытых замерами (стенды `lagtest.html`,
`perftest.html`, `insttest.html` лежали в исходном проекте):

- **число источников света не меняется никогда.** Подключение или снятие
  точечного света заставляет three пересобирать программы всех материалов сцены:
  замер дал средний кадр 13 мс вместо 1.8 и провал до 167 мс. Поэтому свет
  файерболов живёт в пуле и гасится яркостью.
- **частицы и статика — одним вызовом отрисовки.** Искры, гибы и пыль сведены в
  `InstancedMesh`, геометрия рунных печатей слита: восемь печатей давали 1032
  вызова в кадре, стало 24.
