# ФАЄРВОЛ (seriousdoom) — контекст для Claude

Воксельный ретро-шутер на three.js: волны монстров, одна арена, гонорар за
волну. Меню/подача — Doom 1993, устройство волн и твари — Serious Sam.
Отделён от VoxEvasion (там он живёт как мини-игра «Фриланс — отбить DDoS»
в src/minigames; сюда портирован и развивается независимо).

Язык общения с Олегом — русский/украинский. Комментарии в коде — русские,
объясняют «почему», а не «что». Оле́г сам плейтестит и описывает баги;
не гонять долгие проверки — tsc + build + короткое «что проверить».

## Запуск и отладка

```bash
npm run dev          # vite на http://localhost:5180/
npx tsc --noEmit     # типы
npx vite build       # прод-сборка (base './' — готово для itch)
```

- `/assets.html` — витрина всех моделей и звуков (общие модули с игрой)
- Читы: на титуле IDCLEV+2 цифры — прыжок на волну; в адресе `?wave=16`,
  `?perf=1` (счётчик F3), `?edit=1` (сразу в редактор)
- Бенчи в корне: `wave20test.html`, `audiotest.html` (кнопкой), в
  VoxEvasion-minigames ещё `lagtest.html`/`insttest.html`. В сборку не
  попадают (vite собирает только index+assets).
- ВАЖНО про браузерную панель Claude: скрытая вкладка замораживает rAF —
  игра «стоит», время идёт только в момент скриншота. Синтетические
  keydown/mousedown работают; edge-детекция клавиш (стрелки в меню) —
  ненадёжна. Звук WebAudio НЕ замирает: выходи из игры после проверки,
  иначе музыка играет фоном.

## Карта кода

- `src/games/doom.ts` (~3000 строк) — ВСЯ игра: арена, монстры, оружие,
  волны, сложности, HUD, редактор арен. Точки входа по коментарям-секциям.
- `src/games/doomModels.ts` — модели (монстры/оружие/пикапы/структуры),
  ArenaDef + DEFAULT_ARENA + BUILTIN_ARENAS + validateArena, bakeStatic,
  EmberCloud/DustCloud (InstancedMesh-частицы), createPentagram.
- `src/core/three3d.ts` — рантайм: PerspectiveCamera (persp:true),
  HUD-канвас поверх WebGL, ctx.perf (замер кадра), ctx.compile (прогрев).
- `src/core/audioDoom.ts` — сэмплы /sfx, позиционный звук (затухание,
  панорама, ФНЧ вдали), sfx.loop() для непрерывного воя камикадзе.
- `src/core/musicDirector.ts` — main/middle/end/chill с кроссфейдами.
- `src/main.ts` + `index.html` — оболочка (заставка → забег → счёт).

## ДВА ЖЕЛЕЗНЫХ ПРАВИЛА ОТРИСОВКИ (добыты замерами, не нарушать)

1. **Число источников света в сцене не меняется НИКОГДА.** Подключение/
   снятие PointLight = пересборка программ всех материалов: замер давал
   13 мс средний кадр вместо 1.8 и провал 167 мс. Всё световое живёт в
   пулах и гасится intensity=0 (файерболы, ракеты, глаза меню, ствол).
2. **Частицы и статика — минимум вызовов.** Искры/гибы/пыль —
   InstancedMesh (EmberCloud аддитивный, DustCloud с альфой через
   onBeforeCompile). Статика арены запекается bakeStatic (вершинные
   цвета, общий BAKED_MAT с userData.shared — dispose его щадит).
   Монстры: геометрия кеширована на вариант (тип×ветеран), спавн = 2 меша
   + 2 клона материала; вспышка попадания — униформа uFlash, не перекраска.

## Ключевые системы

- **ArenaDef** — арена как данные: size (16..40, шаг 2), sky (hell/dusk/
  day/void), ground (checker/sand/sand_road/stone/cobble), pillars
  (kind: block/obelisk/wall/pyramid/rubble/column/steps/rock/statue/dais,
  rot 0/45/90/135), torches, seals (мин. 2!), pickups, start.
  Хранилище: localStorage fw_arenas {имя:def}, fw_arena_draft, fw_arena_use
  ('default'|'b:N'|'draft'|'u:имя'). validateArena зажимает всё чужое.
  При добавлении нового kind НЕ ЗАБЫТЬ kinds0-белый список в validateArena
  (уже наступали: элементы молча превращались в block).
- **dais (платформа)** — ПРОХОДИМАЯ: groundY(x,z) с пандусом ~1.1 м по
  краю. Высоту знают: камера (EYE+pY), ракеты, файерболы (пуск от m.y,
  попадание по EYE+pY), наземные монстры (m.y=groundY; анимационный
  сдвиг grp.position.y СБРАСЫВАЕТСЯ в начале кадра — иначе копится и
  твари улетают в небо, уже чинили), пикапы, печати, маркер старта.
  Монстры на подъёме замедляются ×0.72.
- **Разгон рогача/прыжок скакуна**: направление заморожено; застревание
  у внутренних стен детектится по факту (<40% намеченного пути за кадр →
  срыв разгона). Не убирать — иначе стоят у стен арена-гейта.
- **Поворот структур** 45°: визуал — повёрнутые подгруппы (bakeStatic
  печёт по matrixWorld), коллизии/LOS — по ОПИСАННОМУ прямоугольнику
  (ex/ez; на 45° шире визуала — осознанный компромисс).
- **Сложности** (DIFFS): звичайна/важка/хардкор — HP тварей НЕ трогаем,
  растут урон/плотность/потолок (26/32/44), лечение скупеет. Выбор в
  титуле, localStorage fw_diff.
- **Оружие**: пистолет/дробовик 3в/пулемёт 6в/ракетница — на 16-й волне
  ЛЕЖИТ НА АРЕНЕ (парит, светится). Ракета: 90 прямого + 70 осколков
  (спад от КРАЯ твари до 5.5 м), самоурон ×0.35 через hurt(). Выдача
  стволов — `wave >= N` (не ===, ломалось при прыжке IDCLEV).
- **Спавн**: печать заряжается 2 с (телеграф, голограмма+искры), потом
  монстр. Очередь pending; wave-clear ждёт и её. У камикадзе непрерывный
  вой sfx.loop, обрывается в gibify.

## Известные компромиссы (не баги)

- хитскан игрока бьёт СКВОЗЬ пилоны (укрытия работают только против
  механоида) — осознанно, менять только по просьбе Олега
- флейр солнца не проверяет заслонение пирамидой
- гибы на платформе визуально проседают в неё (падают до y=0.08)
- 45°-коллизия шире визуала (см. выше)
- iPhone/Ogg: в основном VoxEvasion есть public/audio-check.html для
  проверки; здесь музыка в ogg+m4a, sfx в wav/ogg
